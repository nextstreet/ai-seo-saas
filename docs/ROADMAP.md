# Roadmap

| Phase | Outcome | Exit condition |
| --- | --- | --- |
| V1 Foundation | workspace, Astro, Supabase, shared contracts, tenant/profile | clean install and `pnpm check` pass |
| V1 SEO Model | topics, relations, keywords, candidates, pages | create and inspect an explainable candidate decision |
| V1 Publishing | approved candidate -> Brief -> draft -> review -> page | one reviewed page renders with metadata and links |
| V1 Ita Bag Launch | seed graph and 40–80 intent-led pages | crawlable deployment and sitemap submitted |
| V1.1 Design Loop | concepts, gallery, vote | concept-to-vote loop works with abuse controls |
| V1.2 Social Engine | channel derivatives from assets | one asset produces reviewed channel variants |
| V2 Feedback AI | GSC/social/vote feedback | CREATE/EXPAND/MERGE/IGNORE uses real signals |
| V3 Community | accounts, posts, replies, showcases | proven returning audience requires it |
| V4 SaaS | onboarding, stronger RBAC, billing, templates | second/third industry validates repeatability |

## Launch content composition

The working target is a coherent topical site, not 80 interchangeable blog posts:

- 5–10 core product/category/commercial pages.
- 10–15 feature/component/material pages.
- 10–20 design/application pages.
- 10–20 intent-specific guides.
- 5–10 gallery/inspiration pages.

Final URLs are determined through query/intent clustering and quality review;
the numeric target is not permission to publish thin combinations.
